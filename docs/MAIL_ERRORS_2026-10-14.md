# UniForm21 2.1.1

Исправлена обработка отказов почтового обработчика DLE. Ранее форма показывала успех до проверки результата отправки.

## Изменения

- Успех показывается после обработки всех получателей; send_error, bad_address, false и исключения считаются отказом.
- При полном отказе форма и введённые значения сохраняются. Пользователь видит нейтральное сообщение без SMTP-диагностики.
- При частичном успехе сообщается о неполной отправке и предлагается связаться другим способом, без автоматического повтора.
- Для каждого получателя создаётся отдельный почтовый объект и заново добавляются вложения: DLE очищает их после отправки.
- Положительная проверка настоящего DOC из тестовых данных Apache POI пройдена; поддельный DOC отклонён.

## Обновление с 2.1.0

Обновите общие PHP-файлы engine/ajax/uniform.php, engine/modules/uniform/ и uniform.js вместе. Сохраните свои config.tpl, получателей и шаблоны; укажите ?v=2.1.1 в URL uniform.js, очистите кэш DLE и откройте формы заново. Новых полей конфигурации и изменений БД нет.

## Проверки и ограничения

8 изолированных DOC/почтовых сценариев,22 проверки безопасности,4 проверки вложений и17 проверок лимитов. Почтовый транспорт полностью заменён заглушкой. Реальная доставка SMTP и попадание в ящик не проверялись: отсутствие ошибки обработчика не доказывает доставку.

Неудачная попытка расходует слот лимитера. При повторной отправке прикрепите файлы заново. Часть писем могла быть уже отправлена при частичном отказе; повтор может создать дубли. MIME-проверка не заменяет антивирус.
