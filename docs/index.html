Обзор

Что такое UniForm

UniForm21 - бесплатный модуль универсальных форм для DataLife Engine 21. Адаптация оригинального модуля UniForm (автор - Павел Белоусов (ПафНутиЙ), большое спасибо за разработку!) под актуальные версии DLE и PHP. Лицензия MIT.

📞

callback

Всплывающая форма «Заказать звонок»: телефон (обязательное), имя и удобное время звонка. Удобна для кнопки в шапке сайта.

✉️

feedback

Форма обратной связи: e-mail и текст сообщения обязательны. Копия письма отправляется и посетителю (sendToSender).

🛒

buy

Заказ товара: имя, телефон, e-mail и комментарий. Подходит для кнопки «Купить» на странице товара или услуги.

📄

inline

Встроенная форма без попапа - выводится прямо в тексте любой страницы или статической страницы DLE.

🗺️

main

Встроенная форма быстрого вопроса с e-mail - например, для блока контактов или карты на главной странице.

⚡

Как это работает

Форма подгружается AJAX-запросом, отправляется без перезагрузки, ответ (ошибка или успех) заменяет содержимое формы. Письма уходят штатным механизмом почты DLE.

Установка

Файлы модуля - что где лежит

UniForm21 - standalone-дистрибутив: модуль не привязан к конкретному шаблону и подходит для любого шаблона DLE 21. Раскладка файлов такая:

ПутьНазначение
engine/ajax/uniform.phpТочка входа AJAX-контроллера модуля
engine/modules/uniform/uniform.phpЯдро: сборка формы, валидация, загрузка вложений
engine/modules/uniform/cfg.phpРазбор параметров из config.tpl
engine/modules/uniform/functions.phpВспомогательные функции шаблонизатора форм
engine/modules/uniform/sendmail.phpСборка и отправка писем (через почтовый класс DLE)
templates/{THEME}/uniform/Шаблоны 5 форм + css и js модуля (копируется в папку вашего шаблона)

Установка за 5 шагов

1

Скопируйте файлы движка

Перенесите engine/ajax/uniform.php и папку engine/modules/uniform/ из дистрибутива в корень сайта.

2

Скопируйте шаблоны форм

Папку uniform/ из templates/{THEME}/ дистрибутива - в папку вашего шаблона: templates/ВАШ_ШАБЛОН/uniform/.

3

Подключите CSS и JS в main.tpl

В <head>:

<link href="{THEME}/uniform/css/uniform.css" type="text/css" rel="stylesheet">

Перед </body> (после подключения jQuery движка):

<script src="{THEME}/uniform/js/jquery.ladda.min.js"></script>
<script src="{THEME}/uniform/js/jquery.form.min.js"></script>
<script src="{THEME}/uniform/js/jquery.magnificpopup.min.js"></script>
<script src="{THEME}/uniform/js/uniform.js"></script>
4

Вставьте вызовы форм

Примеры для попапа и встроенной формы - в разделе «Как вызвать форму».

5

Укажите свои e-mail

Во всех пяти config.tpl замените плейсхолдеры emails = mail@mail.ru на свои адреса.

⚠️
Подключайте файлы только прямыми ссылками. Минификатор engine/classes/min удалён из DLE 18+, поэтому старые примеры подключения из документации UniForm 2.0.0 (через пути минификатора) не работают - файлы будут отдавать 403. Используйте прямые ссылки {THEME}/..., как в шаге 3. Попапы работают на Magnific Popup, анимация кнопки отправки - на Ladda (обе библиотеки в комплекте).
Использование

Как вызвать форму

Два режима: всплывающее окно по клику и встроенная форма, загружающаяся сразу при открытии страницы.

Попап (кнопка/ссылка)

Любой элемент с атрибутом data-uniform открывает форму в модальном окне:

<span data-uniform='{"formConfig": "callback"}' class="uf-btn">Заказать звонок</span>

<!-- кнопка покупки на странице товара -->
<button class="thm-btn yellow-bg" data-uniform='{"formConfig": "buy"}'>Купить</button>

<!-- дополнительные скрытые поля передаются прямо в JSON-объекте -->
<!-- их имена нужно разрешить параметром hidden в config.tpl -->
<span data-uniform='{"formConfig": "feedback", "newsid": "{news-id}"}'>Написать автору</span>

Встроенная (inline) форма

Блок с атрибутом data-uniform-inline подгружает форму сразу при загрузке страницы - подходит для страниц «Контакты», «О компании» или блока карты на главной:

<div data-uniform-inline='{"formConfig": "inline"}'>
  <div class="uf-inline-loading"></div>
</div>
💡
Куда вставлять вызовы. В любой .tpl вашего шаблона (например main.tpl, fullstory.tpl, static.tpl) или прямо в текст новости/статической страницы в режиме исходного кода. Классы кнопок (uf-btn, thm-btn и т.п.) - произвольные, стилизуйте под свой шаблон.
Справочник

Структура формы

Каждая форма - отдельная папка внутри templates/{THEME}/uniform/ из трёх файлов: config.tpl (настройки), form.tpl (вёрстка) и email.tpl (шаблон письма).

config.tpl - все параметры

ПараметрПо умолчаниюОписание

emailsfalseАдреса получателей уведомления, через запятую
selectFieldsfalseПоля типа select (чтобы модуль корректно обработал выбранное значение)
checkboxFieldsfalseПоля типа checkbox
radioFieldsfalseПоля типа radio

{* пример поля с подсветкой ошибки и сохранением введённого значения *}
<input class="uf-input [uf_error_phone]uf-input-error[/uf_error_phone]"
       type="text" name="phone" value="{uf_field_phone}">

email.tpl - шаблон письма

Тема письма задаётся блоком [header]…[/header], дальше - HTML-тело письма. Поля подставляются тегами {phone}, {email} и т.д. (имя тега = имя поля формы), а выбранные значения select - блоками вида [uf_select_calltime="9-12"]с 9 до 12[/uf_select_calltime]:

[header]
  Новый заказ звонка с сайта
[/header]
<h2>Новый заказ звонка с сайта</h2>
<b>Телефон:</b> <a href="tel:{phone}">{phone}</a><br>
<b>Когда звонить:</b>
[uf_select_calltime="9-12"]с 9:00 до 12:00[/uf_select_calltime]

Кастомизация

Как создать свою форму

Новая форма делается копированием существующей - например, формы callback.

1

Скопируйте папку формы

Создайте копию папки templates/{THEME}/uniform/callback/ с новым именем, например uniform/order/. Внутри должны остаться config.tpl, form.tpl, email.tpl.

2

Настройте config.tpl

Поменяйте templateFolder = order (имя новой папки), перечислите обязательные поля в required и свои адреса в emails.

3

Отредактируйте form.tpl и email.tpl

Добавьте свои поля. Для каждого поля с name="имя" доступны теги {uf_field_имя} и [uf_error_имя] в форме и {имя} в письме.

4

Вставьте вызов на сайт

Попап: <span data-uniform='{"formConfig": "order"}'>Открыть</span> - в любой tpl шаблона или прямо в текст новости/статической страницы (в режиме исходного кода).

⚠️
Обязательно замените адреса почты! Во всех пяти config.tpl сейчас стоят плейсхолдеры emails = mail@mail.ru (в feedback, buy, inline и main - ещё и mail2@mail.ru). Пока не впишете свои адреса, заявки будут уходить в никуда.
Технические детали

Совместимость с DLE 21 и PHP 8.x

Модуль адаптирован под DataLife Engine 21.0: убраны удалённые из движка функции, добавлены проверки для PHP 8, AJAX переключён на актуальную точку входа.

🚪

Точка входа AJAX

Рабочий URL модуля: /index.php?controller=ajax&mod=uniform&formConfig=<имя>. В DLE 21 весь AJAX идёт через index.php?controller=ajax - js модуля уже настроен на него.

🛡️

403 на прямой вызов - это нормально

Прямое обращение к /engine/ajax/uniform.php всегда отдаёт 403 «Hacking attempt!» - штатная защита модуля от вызова вне движка. Это не ошибка и не признак поломки.

🔐

Защита

CSRF-токен в каждой форме (ошибка сессии - блок [uf_token_error]), проверка IP по бан-листу DLE, санитизация имени формы, фильтрация текста штатным парсером DLE.

📨

Отправка почты

Письма отправляются штатным почтовым классом DLE с настройками из админпанели. На локальном сервере без SMTP письмо может не уйти - сама форма при этом отработает корректно.

💡
Отладка. Если форма ведёт себя неожиданно, раскомментируйте debug = y и nocache = y в её config.tpl - увидите блок [debug] с параметрами и исключите влияние кеша. Не забудьте выключить после настройки.

Что изменено по сравнению с UniForm 2.0.0

Убрана удалённая из DLE 21 функция convert_unicode(), устаревшие вызовы допполей заменены на DLEUserXFields, добавлены isset-проверки для PHP 8, исправлена автозагрузка ParseFilter/HTMLPurifier, AJAX переключён на index.php?controller=ajax. Полный список правок - в README.md дистрибутива.
